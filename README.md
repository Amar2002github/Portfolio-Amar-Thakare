# Amar Thakare Portfolio

A responsive static portfolio inspired by the layout/content structure of the referenced Nehal Raut portfolio, rebuilt with original code and customized for Amar Thakare.

## Included
- Home / Hero
- About
- Skills
- Resume / Education
- Projects
- Certifications
- Contact
- Responsive mobile navigation
- Typing animation
- No build tools required

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Publish on GitHub Pages
1. Create a repository named `Amar2002github.github.io` (or any repository for project pages).
2. Upload all files while preserving the `assets` folder.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save.

## Before publishing
Update the placeholder email and LinkedIn URL in `index.html`. Replace the `AT` avatar with a real profile photo if desired.

## Note
This is an independently written implementation with a similar portfolio structure, not a copy of the original site's source code.
